# 🚗 Vehicle Rental Management System

A desktop-based **Vehicle Rental Management System** built with **Electron.js and Node.js**. The application is designed to simplify vehicle rental operations by providing an organized way to manage vehicles, customers, and rental records through a user-friendly interface.

## ✨ Features

- **Vehicle Management** – Add, view, update, and remove vehicle information.
- **Customer Management** – Maintain customer records and personal information.
- **Rental Management** – Create and manage vehicle rental bookings.
- **Availability Tracking** – Keep track of available and rented vehicles.
- **Rental Records** – View and manage previous and ongoing rental transactions.
- **User-Friendly Interface** – Simple and intuitive desktop application interface.
